# 3A9AR.ma Roadmap

Public product roadmap. Issues are tagged per milestone.

## ✅ Done — v1.0 (released)
- Scraper (Mubawab + Avito), 19,718 properties
- Search + filters (20+ dimensions), Leaflet map
- FR/EN/AR i18n with RTL
- Mortgage calculator (6 banks), price history, valuation
- WhatsApp lead engine, payments (CMI + Stripe)
- Auth + RBAC, admin moderation
- Docker deployment, GitHub Actions CI

## 🔄 In progress — v1.1
- [ ] #1 PWA — installable, offline, push notifications
- [ ] Saved-search alerts via WhatsApp scheduling
- [ ] Agent dashboard analytics v2

## 🗓️ Planned — v1.2
- [ ] #2 ML property valuation model
- [ ] Autocomplete with Meilisearch (souqs, Darija terms)
- [ ] Mobile app (React Native) — q4

## 💡 Future — v2.0
- 3A9AR marketplace for agents (subscriptions + leads)
- Rent payments escrow
- Property management suite
- Arabic voice search (Darija)

## How to contribute
1. Pick an issue from the list above (or the issue tracker)
2. Comment "I'll take this" — it gets assigned to you
3. Open a PR with the fix
4. Get merged and listed in CONTRIBUTORS.md
